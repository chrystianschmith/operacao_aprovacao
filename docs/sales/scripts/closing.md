# Closing Scripts — Operação Aprovação

> Técnicas de fechamento adaptadas para Inside Sales (Auto-serviço + Assistido) + High Touch.
> Princípio: **Fechamento natural = próxima etapa lógica**, não pressão.
> Todas as técnicas assumem: **BANT qualificado + Dor clara + Fit confirmado**.

---

## 1. Princípios de Fechamento (Regra de Ouro)

| Princípio | Aplicação |
|-----------|-----------|
| **Assumptive Close** | Fale como se já tivesse fechado: "Quando você gerar seu primeiro plano..." |
| **Alternative Close** | Duas opções, ambas levam à venda: "Anual (trava preço) ou Mensal (flexibilidade)?" |
| **Urgency Close** | Urgência REAL (timer, estoque, edital): "Bônus mentoria expira em 2h." |
| **Summary Close** | Resuma valor + peça decisão: "Anual R$ 1.997 + Mentoria grátis + Garantia 30d. Bora?" |
| **Takeaway Close** | "Se não for pra agora, sem problema. O preço sobe dia X. Quando quiser voltar..." |
| **Puppy Dog Close** | "Testa 7 dias grátis. Se não gostar, cancela 1 clique. Sem cartão." |
| **Soft Close (Teste)** | "Quer gerar seu plano agora pra ver como fica? Leva 30s." |

**Regra**: **NUNCA** use fechamento agressivo ("Assina agora ou perde pra sempre" falso). Urgência só se REAL.

## 3. Fechamento Assistido (WhatsApp/Call — Closer)

### Cenário 1: Lead Quente — WhatsApp (Pós-Qualificação / Proposta Enviada)

**Fechamento Direto (Assumptive + Alternative)**:
> "Perfeito [Nome]. Mandei no WhatsApp as duas opções:\n\n1️⃣ **Anual R$ 1.997** — Trava preço vitalício + Economia R$ 367/ano + **Mentoria 30min GRÁTIS** essa semana\n2️⃣ **Mensal R$ 197** — Flexibilidade total, cancele quando quiser\n\n**PIX 10% off** nas duas. Garantia 30 dias. Cancel 1 clique.\n\n**Qual você prefere? Anual (trava preço) ou Mensal (flexibilidade)?**\n\nManda 'ANUAL' ou 'MENSAL' que eu te mando o link direto pro checkout já pré-preenchido."

**Se Responder "Anual"**: Envia link checkout com `?plan=annual&bonus=mentoria&pix_discount=10` + "Link direto. 1 clique. Acesso imediato."

**Se Responder "Mensal"**: Envia link `?plan=monthly&trial=7` + "Mensal R$ 197. 7 dias grátis sem cartão. Cancele quando quiser."

**Se Dúvida/Objeção**: "Qual sua maior trava? Preço? Tempo? Confiança? Me diz que eu resolvo agora."

## 4. Fechamento Downsell (Se Recusa Anual / High Touch)

### Script: "Mensal Flex — A Porta de Entrada"
> "Sem problemas [Nome]. Anual é compromisso de 1 ano, entendo.\n\n**Opção Mensal**: R$ 197/mês.\n• Mesma plataforma completa\n• Mesma garantia 30 dias\n• Cancele quando quiser (1 clique)\n• 7 dias grátis SEM CARTÃO\n• Sem preço travado (sobe pra novos)\n\n**Link direto**: [Link `?plan=monthly&trial=7`]\n\n**Testa 7 dias grátis SEM CARTÃO**. Se não gostar, nem cobra. Se gostar, continua mês a mês.\n\nBora testar?"

**Se Aceita**: Envia link `?plan=monthly&trial=7` + "Acesso imediato. Gera seu plano em 30s."

**Se Ainda Não**: "Sem pressão. O link fica salvo aqui no chat. Quando quiser testar, é só clicar. Porta aberta."

## 7. Checklist Fechamento (Pré-Ligação / Pré-Envio Proposta)

- [ ] BANT completo (Score ≥ 25/40)
- [ ] Dor clara + Urgência (Edital / Prova / Meta Pessoal)
- [ ] Fit confirmado (Tempo disponível + Concurso definido)
- [ ] Objeções antecipadas respondidas (Preço, Tempo, Confiança, "Já comprei")
- [ ] Proposta/Link Checkout personalizado pronto (UTMs corretos)
- [ ] Garantia 30d + Cancel 1 clique + PIX 10% off comunicados
- [ ] Order Bump / Upsell TY Page configurados
- [ ] Deep Links App testados (Plano, Dashboard, Checkout)
- [ ] Pixel Events: `InitiateCheckout`, `Purchase` confirmados
- [ ] CRM: Stage `Proposal Sent` / `Qualified Opportunity` atualizado
- [ ] Follow-up sequence agendada (Dia 1, 3, 7, 14)
- [ ] Slack #sales notificado: "Nova Proposta Enviada: [Nome] - R$ [Valor] - [Produto]"
