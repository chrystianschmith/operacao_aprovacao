## 8. Regras de Não-Conflito (Stacks Não Se Sobrepõem)

1. **Black Friday > Tudo** — Se BF ativa, desliga outras ofertas especiais (mantém Evergreen base)
2. **Edital PM > Ano Novo** — Se edital sai em Jan, prioriza Stack Edital (geo-targetado)
3. **Urgência Real > Fake** — Timer só expira de verdade (cookie + server). Não reseta.
4. **Estoque Real > Ilimitado** — Kit Físico 200 unid. Turma VIP 15 vagas. Mentoria 5 vagas/mês.
5. **Downsell Só Se Recusa Upsell** — Não mostra mensal antes de oferecer anual.
6. **Garantia Crescente** — Evergreen 30d → Edital 30d → BF 60d → Win-back 30d. Nunca menor.
6. **Preço Travado Vitalício** — Só Black Friday + Ano Novo 2027. Outras campanhas: "Enquanto ativo".

## 9. Checklist Validação Stack (Antes de Lançar)

- [ ] Preço base + bônus = Valor percebido > 3x preço (Ex: BF R$ 1.497 vs R$ 5.000+ valor)
- [ ] Urgência real (Timer server-side + Estoque real + Data real)
- [ ] Garantia ≥ 30 dias (BF 60d)
- [ ] Downsell claro e pior que upsell (Mensal mais caro/ano, sem bônus, sem preço travado)
- [ ] Afiliado comissionado (20% padrão, 30% BF)
- [ ] Pixel events mapeados: `view_oferta_[stack]`, `click_cta_[stack]`, `purchase_[stack]`
- [ ] UTM padronizado: `utm_campaign=stack_[nome]`
- [ ] Sales/SDR treinados no script da stack
- [ ] Email sequences prontas (Pré, Lançamento, Lembretes, Último dia, Downsell)
- [ ] WhatsApp templates aprovados
- [ ] Landing page testada (Mobile + Desktop + Checkout PIX + Cartão)
