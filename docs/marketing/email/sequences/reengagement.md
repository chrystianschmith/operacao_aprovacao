## Controle de Fluxo Reengajamento

| Condição | Ação |
|----------|------|
| `Purchase` event | Para TUDO → `post_purchase_onboarding` |
| Login App (qualquer dia) | Para sequência → Tag `reactivated` → `post_purchase_onboarding` resumido |
| Clicou "Fazer Diagnóstico" | Tag `quiz_started` → Se completou quiz → `quiz_completed` → Score +30 → SDR Outreach |
| Respondeu email | Para automação → Task SDR "Responder lead reengajado" |
| Unsubscribe | Para tudo → Tag `unsubscribed_permanent` |
| Dia 21 sem ação | Tag `archived_cold` → Remove de listas ativas → Mantém em `archived_cold` para sazonal |
| Edital publicado (API) | Trigger `reengagement_sazonal` imediato (pula fila) |
