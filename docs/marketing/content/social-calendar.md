# Social Media Calendar — 30 Dias (Instagram / Facebook / TikTok / Reels / Stories)

> Objetivo: Top-of-mind + Educação + Prova Social + Soft-sell
> Frequência: **1 Post Feed/Dia + 3 Reels/Semana + Stories Diários**
> Horários: Feed 7h (manhã estudo) | Reels 12h / 19h | Stories 6h / 12h / 18h / 22h
> Métricas: Alcance > 10k/semana | Engajamento > 3% | Cliques Link Bio > 200/semana
